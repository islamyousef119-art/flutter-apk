# Nova Delivery Pro V3

Premium Arabic RTL food-delivery app foundation with polished UI/UX, cart, checkout, orders, favorites, notifications and a real Google Maps tracking screen prepared for live driver/customer coordinates.

## External services to connect later
- Firebase Auth / Firestore / Storage / FCM
- Google Maps API key + billing/SDK configuration
- Routing service for road-aware polyline/ETA
- Payment gateway

The app is intentionally structured so these services can replace the local state without redesigning the UI.
